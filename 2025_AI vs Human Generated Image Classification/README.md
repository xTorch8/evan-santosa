# Deep Learning for AI-Generated Image Detection

### Authors
- Evan Santosa
- Alexander Brian Susanto
- Kriangsky van Tannuwijaya

### Project Description
This project focuses on detecting AI-generated images using deep learning techniques to support media authenticity, security, and trust. The system classifies images as either human-caputered or synthetically generated by AI.

### Background
Rapid advancements in generative AI have enabled models to produce highly photorealistic images at scale. While this innovation powers creative industries, it also raises concerns around misinformation, deepfakes, copyright fraud, and the erosion of public trust in digital media. Traditional visual inspection is no longer sufficient, as synthesized images often bypass human perception. Industry leaders and organizations increasingly require automated methods to verify image authenticity. Hence, this project contributes a practical solution aligned with emerging digital forensics and media integrity usecases.

### Methods
- Dataset
    - AI vs Human-Generated Images
- Data Preprocessing
    - Image Resizing and Normalization
    - Data Splitting
    - Image Augmentation
- Modeling
    - VGG
    - ResNet-18
    - ConvNeXT
- Evaluation
    - Classification Report (F1-Score, Recall, Precision, Accuracy)
    - AUC-ROC

### Results
ResNet-18 achieved the highest overall performance on the testing dataset, reaching 99.57% accuracy and maintaining strong precision, recall, and ROC-AUC scores, indicating excellent generalization within the test distribution. While ConvNeXt did not surpass ResNet-18 in the controlled testing environment, it demonstrated better robustness when applied to real-world images outside the testing set, suggesting stronger adaptability to unseen generative styles and image variations.

### Impacts
This project improves the ability to identify AI-generated images, helping reduce the spread of misinformation and fake content online. It supports media and news organizations in verifying the authenticity of images before publishing, and helps brands and creators protect their original work from synthetic or counterfeit visuals. The detection system can be integrated into content moderation workflows to automatically flag suspicious images, making verification more efficient. Overall, it strengthens digital trust by making it easier to distinguish real photographs from AI-generated imagery.
